# v3.3.3 长图高清渲染、图片高度缓存自愈、子代理拉动思考深度与系统性质量修复实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 彻底根治长图模糊、修复失效图片高度缓存导致的布局崩塌、实现子代理拉动思考深度与运行时生效、修复语义搜索乱召回、推广全局输入防抖与应用图标备份，并增强工作区与并发健壮性。

**Architecture:**
1. **图片层**：在 Coil 请求端解耦长图高度限制对宽度的等比压损，大图查看器显式强制 `Size.ORIGINAL` 高清原图解码；`ImageAspectRatioCache` 支持主动逐出与失效重置；
2. **AI 与子代理层**：`AgentDetailPage` 引入步进滑块 `ReasoningPicker` 交互，打通 `SubAgentTool` -> `SubAgentRuntime` 的 `reasoningLevel` 透传链，区分技能内置 Agent 与自定义 Agent；
3. **数据与搜索层**：`ConversationRepository` 还原 RRF 综合相关度排序；表单输入层建立纯本地 Draft 与 500ms 防抖；
4. **工作区与系统层**：`WorkspaceFileSystem.glob` 引入 mtime 降序排序；`workspace_grep` 补齐 Claude Code 参数；治理协程作用域与 `@Volatile` 内存可见性。

**Tech Stack:** Jetpack Compose, Coil 3, Kotlin Coroutines & Flow, Material 3, Android Room, JUnit 4.

**Spec:** `docs/superpowers/specs/2026-10-03-v3.3.3-long-image-aspect-ratio-subagent-and-quality-fixes-design.md`

## Review Focus
1. 长图直接贴出预览是否在 1080p 屏幕上点对点清晰，绝不在宽度方向被降采样；
2. 失效图片 URL 是否在 `onError` 后彻底释放高度绑定，降级为精致错误占位；
3. 子代理设置思考深度后，实际运行发给大模型的请求是否携带对应的 reasoningLevel；
4. 语义搜索结果是否严格按照语义与全文融合得分排在最前，不再被当天无关消息霸占；
5. 表单快速输入时光标是否绝对平稳跟随、0 回跳。
