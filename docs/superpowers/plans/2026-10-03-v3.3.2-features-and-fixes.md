# v3.3.2 特性与体验修复实现计划 (Features and Fixes Implementation Plan)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 实现闹钟/计时器本地工具、偏好设置自定义应用图标与桌面快捷方式、工作区导入导出悬浮进度条、备份覆盖范围扩展至 agents 目录，并彻底根治 WebDAV/S3/语义搜索等表单输入框快速打字光标回跳与吞字问题。

**Architecture:** 
1. 输入框解耦：将表单组件直接绑定至本地同步 Draft State，配合 500ms LaunchedEffect 防抖持久化到 DataStore，隔离异步数据流反写；
2. 备份扩展：在 `BackupManager` 打包与解压清单中增加 `context.filesDir/agents`；
3. 工作区进度 HUD：`WorkspaceBackup` 暴露文件粒度流式进度回调，`WorkspaceVM` 维护状态流并在 `WorkspacePage` 顶层渲染毛玻璃悬浮卡片；
4. 图标快捷方式：在偏好设置界面与网络之间加入入口，集成 `useCropLauncher` 1:1 裁切，通过 `ShortcutManagerCompat` 添加自适应桌面快捷方式；
5. 闹钟与倒计时：在 `LocalToolOption` 中加入 `AlarmClock`，通过 Android 原生 `AlarmClock` Intent 实现闹钟与计时器创建，并在日历与图表之间布局。

**Tech Stack:** Kotlin, Jetpack Compose, Material Design 3, Coroutines/Flow, DataStore, ShortcutManagerCompat, UCrop, Room.

**Spec:** `docs/superpowers/specs/2026-10-03-v3.3.2-features-and-fixes-design.md`

## Global Constraints
- `compileSdk = 35`, `minSdk = 26`, `targetSdk = 35`
- 遵循 Material 3 与现有 `FormItem` / `CardGroup` UI 规范；
- 闹钟工具不得包含秒表（已剪裁），仅支持 `set_alarm`、`set_timer`、`show_clock`；
- 图标裁切使用现有 `useCropLauncher`，强制 1:1 正方形裁切；
- 不破坏现有承重约束与单元测试。

## Review Focus
1. 输入框在中文输入法或英文快速连击时，光标不得发生任何跳动或退格；
2. 工作区导入导出处理含有上千文件的 rootfs 时，进度条必须平滑更新且不在主线程卡顿；
3. 闹钟 Intent 在未传日期或传了重复日期列表时均能正确组装 Intent Extras；
4. 备份包含空 `agents` 目录或不存在 `agents` 目录时不能抛出异常；
5. 桌面快捷方式在不支持快捷方式的系统或受限权限下优雅降级并给出 Toast 提示。

**Files:**

**Interfaces:**
- Consumes: `Settings.webDavConfig`, `Settings.s3Config`, `Settings.embedder`, `SettingsStore.updateEmbedder`
- Produces: 同步 Draft 绑定 + 防抖落盘机制

- [ ] **Step 1: 改造 WebDavTab 输入框绑定**
  - 在 `WebDavTab.kt` 中声明不受外部 State 异步干扰的本地草稿状态：
    ```kotlin
    var urlDraft by remember { mutableStateOf(webDavConfig.url) }
    var usernameDraft by remember { mutableStateOf(webDavConfig.username) }
    var passwordDraft by remember { mutableStateOf(webDavConfig.password) }
    var pathDraft by remember { mutableStateOf(webDavConfig.path) }
    ```
  - 增加防抖保存机制：
    ```kotlin
    LaunchedEffect(urlDraft, usernameDraft, passwordDraft, pathDraft) {
        delay(500)
        val trimmedUrl = urlDraft.trim()
        val trimmedUser = usernameDraft.trim()
        val trimmedPath = pathDraft.trim()
        if (trimmedUrl != webDavConfig.url || trimmedUser != webDavConfig.username || 
            passwordDraft != webDavConfig.password || trimmedPath != webDavConfig.path) {
            updateWebDavConfig(
                webDavConfig.copy(
                    url = trimmedUrl,
                    username = trimmedUser,
                    password = passwordDraft,
                    path = trimmedPath
                )
            )
        }
    }
    ```
  - 将所有 `OutlinedTextField` 的 `value` 改为绑定对应 `Draft`，`onValueChange` 仅赋给本地 Draft，移除打字过程中的 `it.trim()`。

- [ ] **Step 2: 改造 S3Tab 输入框绑定**
  - 同样在 `S3Tab.kt` 中将 `endpoint`、`accessKeyId`、`secretAccessKey`、`bucket`、`region` 声明为独立本地 Draft；
  - 增加 500ms 防抖更新，打字时不触发 DataStore 写入。

- [ ] **Step 3: 改造 SettingEmbedderPage 输入框绑定**
  - 在 `SettingEmbedderPage.kt` 中，将 `remember(embedder.baseUrl)` 移除外部 key，改为初次初始化：
    ```kotlin
    var baseUrlDraft by remember { mutableStateOf(embedder.baseUrl) }
    var modelDraft by remember { mutableStateOf(embedder.model) }
    var apiKeyDraft by remember { mutableStateOf(embedder.apiKey) }
    ```
  - 增加防抖保存：
    ```kotlin
    LaunchedEffect(baseUrlDraft, modelDraft, apiKeyDraft) {
        delay(500)
        if (baseUrlDraft != embedder.baseUrl || modelDraft != embedder.model || apiKeyDraft != embedder.apiKey) {
            settingsStore.updateEmbedder {
                it.copy(baseUrl = baseUrlDraft.trim(), model = modelDraft.trim(), apiKey = apiKeyDraft.trim())
            }
        }
    }
    ```
