## 1. 核心改进与技术治理

### A. 桌面快捷方式权限引导与系统设置直达
- **背景痛点**：
  - 之前的自定义图标功能通过 `ShortcutManagerCompat.requestPinShortcut` 发送桌面快捷方式；
  - 但绝大多数国内手机厂商系统（MIUI/HyperOS、ColorOS、OriginOS、EMUI/MagicOS 等）默认将各 App 的「创建桌面快捷方式」权限设置为“禁止”且静默丢弃，导致用户裁切图片点击生成后桌面上没有任何反应。
- **治理落地**：
  1. 增加了 `showPermissionGuideDialog` 权限提示引导弹窗，在发起创建请求后向用户明确说明可能被系统静默拦截；
  2. 实现 `openAppShortcutPermissionSettings(context)`，按优先级自动匹配：
     - 小米/红米：`miui.intent.action.APP_PERM_EDITOR`
     - 华为/荣耀：`com.huawei.permissionmanager.ui.MainActivity`
     - OPPO/一加/realme：`com.coloros.safecenter.permission.PermissionManagerActivity`
     - vivo/iQOO：`com.vivo.permissionmanager.activity.SoftPermissionDetailActivity`
     - 兜底回落：标准 `Settings.ACTION_APPLICATION_DETAILS_SETTINGS`
  3. 设置页中新增「开启桌面快捷方式权限」条目，支持一键直达系统设置。
- **关联文件**：`SettingPreferencesAppIconPage.kt`。

### B. 彻底切除行内公式伪滚动，100% 恢复长按文本复制与纯净排版
- **决断依据**：
  - Compose 的 `InlineTextContent` 是文本流内部的原子插槽，强行在里面挂载滚动容器与手势拦截，不仅无法打破文本引擎对内联插槽固定尺寸的物理约束，更严重的是直接破坏了 `SelectionContainer` 对气泡文字的长按选择、双击取词与全局复制菜单；
  - 强行钳制占位符宽度还会引发不自然的折行与大空行。
- **彻底切除与纯粹保留**：
  1. 彻底移除 `Modifier.formulaScrollable`、`Box.horizontalScroll` 与 `DisableSelection`；
  2. 占位符宽度恢复纯净自然测量：`with(density) { m.widthPx.toSp() }`，公式跟随文本流自然折行，杜绝强制满宽引发的大空行；
  3. 气泡外层 `SelectionContainer` 重新无缝接管全文，长按文本复制、双击选区 100% 恢复原生体验；
  4. 纯粹保留对称式半高扩展基线对齐算法（等号与分数线像素级水平共线）、列表圈符基线穿透（`propagateFirstBaseline`）与特殊 Unicode 生物学符号容错（`♀`、`♂`）。
- **关联文件**：`Markdown.kt`, `LatexText.kt`, `LatexSplitter.kt`。

### C. 图片全链路 8000px 阈值与 GPU 双线性平滑缩放
- 单边硬门禁统一放宽至 8000px，杜绝 16000px 的 1GB 内存 OOM 隐患与 Claude 8000px API 报错；
- 引入以目标尺寸为下限的预采样配合 GPU 双线性插值平滑缩放，彻底消灭长图短边被粗暴除以 4/8 腰斩至 270px 的模糊顽疾；
- 识图工具 `read_image` 规格放宽至 48MB / 16 张 / 45s 超时。
- **关联文件**：`CropLauncher.kt`, `ImageUtils.kt`, `FileEncoder.kt`, `ReadImageTools.kt`。

### D. KeepAliveService 切换为 specialUse 与 Termux 级保活
- 前台服务类型重构为 `specialUse`，附加 `PROPERTY_SPECIAL_USE_FGS_SUBTYPE`，彻底消除 6 小时强制超时抛出的 `ForegroundServiceDidNotStopInTimeException` 强杀崩溃；
- 引入类似 Termux 的 CPU 唤醒锁 `PARTIAL_WAKE_LOCK`，防止手机息屏时 CPU 休眠冻结进程；
- Android 14 (API 34) 模拟器实测 dumpsys 验证 100% 正常生效。
- **关联文件**：`AndroidManifest.xml`, `KeepAliveService.kt`。
