## 2. 核心攻坚战果与落地细节 (Achievements & Technical Details)

### 2.1 长图高清渲染与大图独立原图解码 (`ZoomableAsyncImage.kt`, `ImagePreviewDialog.kt`)
- **列表长图解码解耦**：
  - 针对竖长图（`ratio < 1f`），在 Coil 请求中指定 `size(Dimension(screenWidth), Dimension.Undefined)`，仅约束宽度对齐屏幕物理宽度，解除高度限制对宽度的惩罚性等比压缩；
  - 针对超长图（`ratio < 0.5f`）显式关闭硬件位图（`allowHardware(!export && !isUltraLong)`），彻底消除 Android OpenGL 纹理尺寸上限导致的黑块与崩溃。
- **全屏图片查看器隔离缓存**：
  - `ImagePreviewDialog` 显式构建 `ImageRequest`，指定 `size(coil3.size.Size.ORIGINAL)`、`precision(coil3.size.Precision.EXACT)` 与 `allowHardware(false)`，绕过聊天列表中已被降采样的内存缓存，实现 100% 原始点对点高清渲染。

### 2.2 图片高度展示缓存自愈与优雅错误卡片 (`ImageAspectRatioCache.kt`, `ZoomableAsyncImage.kt`)
- **主动逐出与比例限制**：
  - `ImageAspectRatioCache` 增加 `@Synchronized fun remove(model: String?)` 接口；
  - 在 `put` 中将记录比例限制在 `0.15f .. 6.0f` 安全边界内，杜绝畸形数据撑爆视口；
- **错误态自愈与重试**：
  - `ZoomableAsyncImage` 在 `onError` 时立刻调用 `remove(model)` 并置空本地 `cachedAspectRatio`，彻底释放幽灵高度绑定；
  - 渲染优雅的弱化错误卡片（固定高度 80dp），展示 `HugeIcons.Image02` 弱化图标与文字提示，点击即可平滑重试加载。

### 2.3 子代理拉动思考深度与运行时执行全链路打通 (`AgentDetailPage.kt`, `SubAgentsPage.kt`, `SubAgentTool.kt`, `SubAgentRuntime.kt`)
- **步进滑块交互**：
  - `AgentDetailPage` 替换原 `ExposedDropdownMenuBox` 为 `Card` 容器；
  - 顶部集成 `FilterChip` 切换“继承主助手”；激活自定义时展示带 `Idea`、`Idea01`、`ReasoningLow/Medium/High` 图标的平滑步进 `Slider`；
  - 新建 Agent 保存时增加 `^[a-zA-Z0-9_-]+$` 正则校验，杜绝非法路径字符；
- **运行时透传打通**：
  - `SubAgentTool` 在 `executeAsync` 与 `executeSync` 时透传 `agentDef.effort`；
  - `SubAgentRuntime` 解析 `reasoningEffort` 并转为 `ReasoningLevel`，优先赋给 `TextGenerationParams.reasoningLevel`；
- **技能 Agent 保护**：
  - `SubAgentsPage` 为来自技能的 Agent（名字含冒号）展示 `[技能内置]` 标识 Chip，并隐藏删除菜单选项。

### 2.4 语义搜索乱召回彻底根除与全量输入防抖 (`ConversationRepository.kt`, `SettingModelPromptPage.kt`, `SettingPreferencesNetworkPage.kt`, `AssistantPromptPage.kt`, `SettingPreferencesAppIconPage.kt`)
- **语义搜索乱召回根治**：
  - 查明历史挂起的乱召回根因：`ConversationRepository.kt` 在计算完全文与语义倒数排名融合后，紧接着使用了 `.sortedByDescending { it.date }` 粗暴抹去了所有相关度得分；
  - 彻底移除按日期覆盖排序，恢复 RRF 倒数排名融合得分降序输出，保证最相关的消息始终排在第一位；
- **全量输入防抖**：
  - `SettingModelPromptPage.kt`（内置 Prompt）与 `SettingPreferencesNetworkPage.kt`（User-Agent）引入本地同步 Draft 状态解耦输入流，配合 500ms `LaunchedEffect` 防抖异步落盘；
  - `AssistantPromptPage.kt` 为 `systemPrompt` 的 `snapshotFlow` 增加 `.debounce(500)`，避免每次按键高频触发 Room 数据库写入；
- **应用图标自动备份**：
  - 图标存储路径收敛至 `context.filesDir/images/custom_app_icon.png`，自动继承 `BackupManager` 的备份覆盖，并静默迁移存量文件。

### 2.5 工作区与代码并发健壮性 (`WorkspaceFileSystem.kt`, `WorkspaceTools.kt`, `TTS.kt`, `ProotShellRunner.kt`, `SearchService.kt`)
- **工作区 glob mtime 排序**：`WorkspaceFileSystem.glob` 在截断前先按 `file.lastModified()` 降序排序，最新文件优先展示；
- **workspace_grep 参数扩充**：补齐 `ignore_case`（默认 true）、`output_mode`（`"content" | "files_with_matches" | "count"`）、`head_limit` 参数支持；
- **并发与泄露修复**：`CustomTtsStateImpl` 作用域绑定 `SupervisorJob()` 并在 `cleanup()` 中执行 `scope.cancel()`；`ProotShellRunner` 静态闭包增加 `@Volatile`；收敛 `SearchService.withSingleKey` 分支。
