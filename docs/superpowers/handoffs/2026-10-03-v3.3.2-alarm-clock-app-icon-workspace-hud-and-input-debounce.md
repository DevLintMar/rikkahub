## 2. 核心攻坚战果与落地细节 (Achievements & Technical Details)

### 2.1 根治输入框打字过快光标回跳与丢字 (`WebDavTab.kt`, `S3Tab.kt`, `SettingEmbedderPage.kt`)
- **深层根因**：原实现将 `OutlinedTextField` 的 `value` 直接绑定到异步的 `StateFlow` 或使用了带外部 key 的 `remember(embedder.baseUrl)`，且在 `onValueChange` 中直接执行 DataStore 挂起写入并伴随 `it.trim()`。快速击键时，前一个字符的异步磁盘写入完成触发 State 重新向上发射，强行重置了 Compose 内部正在输入的文本缓冲区与光标位置，导致光标回跳和丢字。
- **解决方案**：
  - 引入输入层与持久化层的完全解耦模式：声明纯本地的同步 `Draft` 状态，`onValueChange` 仅赋给本地 Draft，输入过程 100% 保持在 120fps 帧同步内，0 延迟、光标绝对跟随；
  - 配合 `LaunchedEffect` 与 500ms 防抖静默落盘到 DataStore，并在页面销毁 (`DisposableEffect.onDispose`) 及主动点击测试/备份/重建按钮前立即调用 `flushDraft()` 确保数据不漏。

### 2.2 备份系统扩展与自定义 Agent 目录纳入 (`BackupManager.kt`, `BackupManagerAgentsTest.kt`)
- **扩展清单**：在 `BackupManager.kt` 的文件打包与解压白名单中正式引入 `AGENTS_FOLDER = "agents"`，将用户通过子代理或手动创建的 `context.filesDir/agents/*.md` 纳入日常备份包；
- **架构加固**：将 `isAttachment` 抽取为 `companion object` 的 `internal` 方法，补齐完备的单元测试覆盖；彻底规避了 KDoc 块注释内由于 `/agents/*` 语法引发的嵌套注释解析陷阱。

### 2.3 工作区导入导出屏幕悬浮进度条 (`WorkspaceBackup.kt`, `WorkspaceRepository.kt`, `WorkspaceVM.kt`, `WorkspacePage.kt`)
- **流式进度追踪**：
  - `WorkspaceBackup.export`：预扫描工作区目录总文件数，在流式写入每个文件条目时触发 `onProgress(current, total, path)` 回调；
  - `WorkspaceBackup.extractTo`：以 `zip.size()` 为基准，在逐条解压普通文件与重建符号链接时触发进度回调；
- **悬浮毛玻璃 HUD**：
  - `WorkspacePage` 顶层增加半透明防误触蒙层与悬浮毛玻璃卡片；
  - 显示动态标题（“正在导出工作区...” / “正在导入工作区...”）、`LinearProgressIndicator` 平滑进度条、文件计数标签（如 `450 / 1200 个文件 (37%)`）与当前处理路径微字提示，处理完成后自动淡出。

### 2.4 偏好设置自定义应用图标与桌面快捷方式 (`SettingPreferencesAppIconPage.kt`, `SettingPreferencesPage.kt`, `RouteActivity.kt`)
- **入口编排**：在 `SettingPreferencesPage.kt` 中严格置于**「界面偏好设置」与「网络」之间**；
- **自主切图与桌面快捷方式**：
  - 接入 `useCropLauncher`，强制 1:1 正方形 UCrop 裁切并保存为 `custom_app_icon.png`；
  - 阐明 Android 系统底层关于 APK 安装包主图标只读的安全机制，采用官方标准的 `ShortcutManagerCompat.requestPinShortcut` + `IconCompat.createWithAdaptiveBitmap` 生成专属桌面启动快捷方式，点击秒开应用；
  - 支持恢复默认图标与友好原理解释。

### 2.5 闹钟与倒计时助手本地工具 (`AlarmClockTool.kt`, `LocalTools.kt`, `AssistantLocalToolPage.kt`, `BuiltinToolUIs.kt`)
- **功能剪裁与聚焦**：依用户要求彻底移除秒表，纯粹聚焦于系统闹钟 (`set_alarm`)、倒计时计时器 (`set_timer`) 与打开时钟 (`show_clock`)；
- **免弹窗静默权限**：采用 Android 原生 `AlarmClock` 意图，声明 `com.android.alarm.permission.SET_ALARM`（普通权限，系统自动授予，无需像日历那样弹窗请求）；
- **布局编排**：在 `AssistantLocalToolPage.kt` 中严格置于 **`Calendar`（日历）之后、`ChartDisplay`（图表显示）之前**；
- **气泡卡片**：在 `BuiltinToolUIs.kt` 中实现 `AlarmClockToolUI`，展示 `HugeIcons.Time02` 时钟图标、格式化时间与执行结果状态卡片。
