## 1. 核心改进与技术突破

### A. 图片全链路重构与平滑双线性缩放 (8000px 阈值)
- **背景痛点**：
  - 之前单边限制在 4000px，且完全依靠 Android 原生 inSampleSize（2 的次幂）下采样；
  - 导致 1080x8500 的长截图在高度超过 4000 后，短边宽度被强制除以 4 暴跌至 270px，文字严重粘连模糊。
- **解决方案**：
  - 将单边硬门禁统一放宽至 **8,000px**（完美贴合 Claude 官方 API 8000px 红线，同时杜绝超大图 1GB 内存 OOM 隐患）；
  - 升级为两阶段缩放重采样管线：
    1. `calculateImageInSampleSize`：以精确目标尺寸为下限进行安全粗预采样，长截图保持 `sampleSize = 1`；
    2. `scaleBitmapIfNeeded`：利用 `Bitmap.createScaledBitmap(..., filter = true)` 进行 GPU 双线性插值平滑缩小至精确目标，彻底杜绝粗暴腰斩，短边保持千像素级别清晰度。
- **关联文件**：`CropLauncher.kt`, `ImageUtils.kt`, `FileEncoder.kt`, `FileEncoderExifTransformTest.kt`。

### B. 识图工具容量放宽 (`read_image`)
- **规格扩容**：
  - 单次读取图片数由 8 张扩容至 **16 张** (`READ_IMAGE_MAX_IMAGES_PER_CALL = 16`)；
  - 单图体积上限由 32MB 扩容至 **48MB** (`READ_IMAGE_MAX_DOWNLOAD_BYTES = 48MB`)；
  - 超时门禁由 20 秒放宽至 **45 秒** (`READ_IMAGE_TIMEOUT_SECONDS = 45L`)；
  - 修正 Prompt 工具描述中的 `max 8 MB` 为统一真实的 `max 48 MB`。
- **关联文件**：`ReadImageTools.kt`。

### C. 行内公式排版治理与手势穿透滑动 ([Image #49])
- **背景痛点**：
  - 列表项包含大分式长公式时，圈符 `o` 悬挂在顶端半空，右侧产生整行大空行；
  - 公式溢出屏幕边缘后无法滑动。
- **深度根因与修复**：
  1. `LatexSplitter` 遇到 `♀`、`♂` 等特殊 Unicode 字符时 RaTeX 测量报错返回 null，导致公式拆分直接失效。修复：增加 `sanitizeLatexForMeasurement`，清洗后测量，成功在顶层等号处将长公式拆分为同行段与换行段；
  2. 公式首端无脑插入 `​` 触发多余软换行。修复：仅在 `index > 0` 的段间插入 `​`，首端不插，圈符同行首段完美对齐，大空行彻底消灭；
  3. 外层 `SelectionContainer` 劫持拖拽手势。修复：在公式滑动组件上挂载专用 `pointerInput`，在横向拖动时显式调用 `change.consume()` 抢先消费事件，并调用 `dispatchRawDelta(-dragAmount)` 驱动滚动，100% 恢复丝滑横滑。
- **关联文件**：`LatexSplitter.kt`, `Markdown.kt`。

### D. KeepAliveService 切换为 specialUse 与 Termux 级保活
- **背景痛点**：
  - 用户在 Android 14+ 设备上遇到 `ForegroundServiceDidNotStopInTimeException` 崩溃强杀；
  - 根因为原先声明为了 `dataSync`，触发了 Android 14 对 dataSync 的 6 小时强制超时杀进程契约。
- **Termux 式长效保活落地**：
  1. `AndroidManifest.xml` 与 `KeepAliveService.kt` 将前台服务类型重构为 `specialUse`，附加 `PROPERTY_SPECIAL_USE_FGS_SUBTYPE` 声明，彻底免除超时强杀；
  2. 引入类似 Termux 的 CPU 唤醒锁 `PARTIAL_WAKE_LOCK`（`setReferenceCounted(false)`），在服务启动时获取、销毁时释放，确保息屏状态下 CPU 持续运转不被系统休眠冻结。
- **实测验证**：在 Android 14 (API 34) 模拟器上实机运行，`dumpsys activity services` 确认 `types=40000000 (specialUse)`，`dumpsys power` 确认 `KeepAliveService:WakeLock` 正常生效持有，0 崩溃。
- **关联文件**：`AndroidManifest.xml`, `KeepAliveService.kt`。
