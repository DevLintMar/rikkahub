## 一、 本阶段战役核心攻坚与交付成果

本阶段聚焦攻坚 UI 交互与视觉精雕、聊天体验与卡顿感深度治理（三大抓手落地、遮罩并发修复与回退）、工作区图片重载死锁根除，并完成 v3.3.4 正式版本发布：

1. **倒计时与闹钟概览提示居中与紧凑化精调**：
   - **倒计时概览重心居中**（`BuiltinToolUIs.kt`）：将工具调用链概览中数字+字母的下漂偏移微调为 `modifier = Modifier.offset(y = (-0.5).dp)`，介于以前未下漂的 `0dp` 与上一版本的 `-1dp` 之间，在单行等宽文本行内实现完美的绝对垂直几何居中。
   - **闹钟与倒计时卡片精致紧凑化**（`BuiltinToolUIs.kt`）：卡片形状调整为 `RoundedCornerShape(6.dp)`，内边距收敛至 `padding(horizontal = 6.dp, vertical = 2.5.dp)`，图标微缩至 `13.dp`，文字样式精炼为 `MaterialTheme.typography.labelLarge.copy(fontFamily = FontFamily.Monospace)`（从原先 16sp 的 `titleMedium` 降至紧凑精巧的 14sp 等宽粗体），卡片整体与上下文 `ToolPill` 高度完美相称。
2. **气泡流式生成期间彻底消灭列表高度抖动**（`ChatMessage.kt`）：
   - 提取流式输出状态 `val isStreaming = loading && lastMessage` 并透传至 `MessagePartsBlock`；
   - 思考过程卡片（`ChainOfThought`）与助理气泡（`Surface` / `MarkdownBlock`）在 `isStreaming` 期间**关闭 `animateContentSize()` 动画**，生成结束后平滑恢复；彻底消除高频吐字期间动画插值与实际高度争抢引发的剧烈上下抽搐与跳动。
3. **思考过程（Reasoning）100dp 折叠预览态手势冲突根除**（`ChatMessageReasoning.kt`）：
   - 彻底剥离预览态内部的 `.verticalScroll(scrollState)` 滚动截胡，消灭滑屏滑经 100dp 区域时的外层断触与手势竞争；
   - 预览区全域增加无水波纹点击事件（`Modifier.clickable(indication = null) { state.onExpandedChange(true, loading) }`），点击 100dp 预览区任意位置即可一键平滑展开为完整内容；
   - 预览态禁用内部文本选择（`SelectionContainer`），展开后自动就绪，彻底避免长按选中手势干扰展开。
4. **自动跟随滚动（Auto Scroll）主动上滑打断保护**（`ChatList.kt`）：
   - 引入 `userScrolledUp` 状态并监听 `snapshotFlow { state.isScrollInProgress to state.canScrollForward }`；
   - 当用户在打字期间主动向上滑动查看历史内容时，自动滚动跟随**立即安静暂停**，绝不再强行把列表拽回底部；
   - 当用户重新滑回底部（`!canScrollForward`）或点击右下角“跳转到底部”悬浮按钮时，自动恢复底部跟随模式，交互丝滑自然。
5. **性能与预热三大抓手深度打通**（`Markdown.kt` + `ChatPrewarm.kt`）：
   - **抓手 1：公式 DisplayList 全量后台预编译**：在 `Markdown.kt` 建立 `collectLatexFormulas`，直接遍历 AST 树中的 `GFMElementTypes.BLOCK_MATH` 与 `INLINE_MATH` 节点，提取公式并调用 `prewarmLatex`，在后台线程批量调用 `getOrCreateDisplayList` 将公式填充进 256 容量的进程级 LRU 静态缓存池，视口内所有行内与块级公式首帧 100% 内存就绪，UI 主线程 Rust JNI 调用降至 0。
   - **抓手 2：图片尺寸与解码后台预加载**：在 `Markdown.kt` 建立 `collectImageUrls` 从 AST 树中提取链接，本地文件通过 `BitmapFactory.Options(inJustDecodeBounds = true)` 毫秒级提取物理宽高并直接登记至 `ImageAspectRatioCache`，远程图片通过 Coil `imageLoader.execute` 预解码进内存缓存并写入真实比例；彻底消灭图片首入视口时 1:1 正方形占位的剧烈高度弹跳与闪白。
   - **抓手 3：首屏富文本段落预烘焙**：预热链路整合 Markdown AST 缓存、Prism.js 代码高亮预编译与公式缓存，首屏段落绘制首帧命中率 100%。
6. **切换对话遮罩方案治理、10条预热与经典质感回退**（`ChatList.kt` + `ChatPrewarm.kt`）：
   - **解耦结构化并发**：预热子任务改为直接由外层 `scope.launch(Dispatchers.Default)` 启动，彻底解除 `withTimeoutOrNull` 强制等待所有子协程完成的父子绑定，规避了全量历史消息阻塞遮罩释放的隐患；
   - **预热数量扩大至最新 10 条**：`priorityCount = 10`，覆盖整屏及其上下文；稳定采样 `while (stable < 3 || !priorityReady)` 严格保证必须等最新 10 条全部预热完成后再撤销遮罩，随后剩余历史消息在后台默默跑完；
   - **点击切对话首帧直出转圈零卡顿**：切换会话时遮罩首帧立即呈现，所有的计算、解析全部转移至后台协程，主线程零卡顿；
   - **遮罩质感回退经典纯白铁板+大旋转环**：回退为原本经典的背景底色（`background`）+ 48dp 大 Spinner（`strokeWidth = 5.dp`），过渡时间 300ms，100% 遮蔽底层排版过程。
7. **工作区图片加载失败重新加载无效彻底根治**（`ZoomableAsyncImage.kt`）：
   - **根本原因排查**：初次解析出真机宿主路径（`file:/data/user/0/...`）后，点击重试时若将该路径再次传给 `WorkspaceFileUrlResolver`，被一票否决为 null，且 Coil 内存缓存记住了失败状态未清除；
   - **物理宿主文件直接判定与直投**：重构 `resolveActualImageSource`，对于物理宿主文件直接判定是否存在且 `length() > 0`，优先以 `java.io.File` 对象原生投喂给 Coil；沙箱路径自动补齐双斜杠与相对路径自愈；
   - **重载点击事件解死锁**：点击“重新加载”时，显式清空 Coil 内存缓存，在 `ImageRequest.Builder` 中启用 `CachePolicy.WRITE_ONLY` 强制重新读盘解码，重新探测非空物理文件，彻底消除重载死锁。
8. **版本号正式递增**：
   - `app/build.gradle.kts` 版本号正式递增为 **3.3.4 (1181)**。
