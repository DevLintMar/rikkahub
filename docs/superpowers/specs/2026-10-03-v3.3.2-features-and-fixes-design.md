# 2026-10-03 RikkaHub 综合特性与体验修复设计规范 (v3.3.2)

## 1. 概述与核心目标 (Overview & Objectives)
本规范涵盖 5 项经过深入调研与确认的系统功能与体验问题修复：
1. **输入框打字过快光标跟不上/回跳根治**：彻底消除 WebDAV、S3、语义搜索配置等页面由于“外部异步状态流实时反写”导致的光标回跳与输入吞字；
2. **备份覆盖范围完善**：将自定义 Agent 目录（`context.filesDir/agents/`）纳入备份，健全语义搜索与保活设置的持久化和跨版本迁移；
3. **工作区导入导出悬浮进度条**：为大体积沙箱工作区的导出与导入提供实时文件级/百分比的屏幕悬浮 HUD 进度条，告别黑盒盲等；
4. **自定义应用图标功能**：在偏好设置（界面偏好与网络之间）增加应用图标设置，支持用户自行上传图片、调用 UCrop 裁切组件，并通过 Android 原生 `ShortcutManager` 生成桌面自定义快捷方式以及应用内 Logo 替换；
5. **闹钟与倒计时本地工具**：在助手本地工具的日历和图表显示之间新增 `AlarmClock` 工具，支持模型为用户创建系统闹钟、设置倒计时器与打开时钟。

## 2. 模块细化设计 (Detailed Design)

### 2.1 模块一：输入框光标跳动与跟不上根治
- **涉及文件**：
  - `app/src/main/java/me/rerere/rikkahub/ui/pages/backup/tabs/WebDavTab.kt`
  - `app/src/main/java/me/rerere/rikkahub/ui/pages/backup/tabs/S3Tab.kt`
  - `app/src/main/java/me/rerere/rikkahub/ui/pages/setting/SettingEmbedderPage.kt`
- **问题根因**：
  1. `WebDavTab` / `S3Tab` 直接将 `OutlinedTextField` 的 `value` 绑定至异步的 `StateFlow`（`settings.webDavConfig.url`），并在 `onValueChange` 中直接执行 `updateWebDavConfig(...)` 触发 DataStore 磁盘写入。打字过快时，前一个字符的 DataStore 回写完成并向上发射，强行重置了正在输入的 Compose 本地缓冲区，导致光标回跳与丢字；`it.trim()` 还在打字过程中过早剥离空格。
  2. `SettingEmbedderPage` 虽然有 `mutableStateOf`，但使用了 `remember(embedder.baseUrl)`。当异步写入完成导致 `embedder.baseUrl` 变化时，`remember` 判定 key 变化并重新初始化，销毁并重置了正在输入的 Draft 状态。
- **解决方案**：
  - 引入输入层与持久化层的完全解耦模式：
    - `var urlDraft by remember { mutableStateOf(initialValue) }`（不带会引发重置的外部 key）；
    - `OutlinedTextField` 100% 绑定本地 `urlDraft`，`onValueChange = { urlDraft = it }`，保持 120fps 本地同步；
    - 使用 `LaunchedEffect(urlDraft)` 配合 `delay(500)`（防抖）进行后台静默落盘；
    - 在失去焦点或页面退出时做最终落盘兜底。

### 2.2 模块二：备份覆盖范围与配置健全
- **涉及文件**：
  - `app/src/main/java/me/rerere/rikkahub/data/sync/BackupManager.kt`
  - `app/src/main/java/me/rerere/rikkahub/data/datastore/migration/SettingsJsonMigrator.kt`
  - `app/src/main/java/me/rerere/rikkahub/data/datastore/PreferencesStore.kt`
- **设计方案**：
  1. 在 `BackupManager.kt` 的文件备份目录列表中，增加 `agents` 目录：
     ```kotlin
     for (folder in listOf(
         FileFolders.UPLOAD, FileFolders.SKILLS, FileFolders.FONTS, IMAGES_FOLDER, "agents"
     ))
     ```
     在恢复解压时一并恢复 `agents/`。
  2. 审计 `SettingsJsonMigrator.kt`，确保在旧版本备份缺少 `embedder` 或 `keepAliveEnabled` 时，保持默认值并正确填充，防止反序列化异常。

### 2.3 模块三：工作区导入导出悬浮进度条
- **涉及文件**：
  - `app/src/main/java/me/rerere/rikkahub/data/sync/WorkspaceBackup.kt`
  - `app/src/main/java/me/rerere/rikkahub/data/repository/WorkspaceRepository.kt`
  - `app/src/main/java/me/rerere/rikkahub/ui/pages/extensions/workspace/WorkspaceVM.kt`
  - `app/src/main/java/me/rerere/rikkahub/ui/pages/extensions/workspace/WorkspacePage.kt`
- **设计方案**：
  1. 数据模型：
     ```kotlin
     data class WorkspaceProgress(
         val title: String,
         val current: Int,
         val total: Int,
         val currentPath: String = ""
     )
     ```
  2. `WorkspaceBackup.kt` 改造：
     - `export`：预扫描目录文件总数 `totalFiles`，在 `addDirectoryToZip` 中每写入一个文件调用 `onProgress(current, total, relativePath)` 回调；
     - `extractTo`：通过 `zip.size()` 获取总条目数，解压每个条目时触发进度回调。
  3. `WorkspaceRepository` / `WorkspaceVM`：
     - 增加 `val progress = MutableStateFlow<WorkspaceProgress?>(null)`；
     - 导入/导出时实时更新此状态流。
  4. `WorkspacePage.kt` 悬浮 HUD UI：
     - 当 `progress != null` 时，在界面顶层渲染半透明防误触蒙层 + 毛玻璃卡片；
     - 卡片内含：动态标题（导出中/导入中）、`LinearProgressIndicator`（支持精确进度或平滑动画）、处理计数（如 `450 / 1200`）、当前处理文件路径（单行省略）。完成后平滑消失。

### 2.4 模块四：自定义应用图标与桌面快捷方式
- **涉及文件**：
  - `app/src/main/java/me/rerere/rikkahub/ui/pages/setting/SettingPreferencesPage.kt`
  - `app/src/main/java/me/rerere/rikkahub/ui/pages/setting/SettingPreferencesAppIconPage.kt` (新增)
  - `app/src/main/java/me/rerere/rikkahub/ui/components/ai/CropLauncher.kt`
  - `app/src/main/java/me/rerere/rikkahub/RouteActivity.kt`
- **设计方案**：
  1. 页面导航与入口：
     - 在 `SettingPreferencesPage.kt` 中，在 `界面偏好设置` 与 `网络` 之间增加条目：
       - 标题：`应用图标`
       - 副标题：`自定义应用图标与桌面快捷方式`
       - 路由：`Screen.SettingPreferencesAppIcon`
  2. 切图与上传：
     - 使用 `useCropLauncher`，设置 `aspectRatio = 1f to 1f`，`freeStyleCropEnabled = false`（锁死 1:1 正方形切图）；
     - 用户从相册选图后，进入 UCrop 完成裁切。
  3. 桌面快捷方式生成：
     - 裁切结果保存为 `File(context.filesDir, "custom_app_icon.png")`；
     - 解码为 Bitmap，使用 `ShortcutManagerCompat.requestPinShortcut`（兼容 Android 8.0+）：
       - `shortcutId = "rikkahub_custom_launcher"`
       - `icon = IconCompat.createWithAdaptiveBitmap(bitmap)`（自适应圆角与形状）
       - `intent = Intent(context, RouteActivity::class.java).setAction(Intent.ACTION_MAIN)`
       - 提示用户“已请求将图标添加至手机桌面”。
  4. 应用内 Logo 联动：
     - 在 `DisplaySetting` 或数据存储中记录自定义图标 URI；
     - 在侧边栏抽屉顶部与关于页面展示该自定义图标。

### 2.5 模块五：闹钟与倒计时本地工具
- **涉及文件**：
  - `app/src/main/java/me/rerere/rikkahub/data/ai/tools/local/LocalToolOption.kt`
  - `app/src/main/java/me/rerere/rikkahub/data/ai/tools/local/AlarmClockTool.kt` (新增)
  - `app/src/main/java/me/rerere/rikkahub/data/ai/tools/local/LocalTools.kt`
  - `app/src/main/java/me/rerere/rikkahub/ui/pages/assistant/detail/AssistantLocalToolPage.kt`
  - `app/src/main/java/me/rerere/rikkahub/ui/components/message/tools/BuiltinToolUIs.kt`
  - `app/src/main/AndroidManifest.xml` (增加 `SET_ALARM` 权限)
- **设计方案**：
  1. 权限配置：
     - `AndroidManifest.xml` 中增加 `<uses-permission android:name="com.android.alarm.permission.SET_ALARM" />`（Normal 权限，无需动态请求）。
  2. 本地工具选项：
     - `LocalToolOption` 增加 `AlarmClock : LocalToolOption()`；
     - `AssistantLocalToolPage.kt` 中排在 `Calendar` 之后、`ChartDisplay` 之前。
  3. 工具实现 (`AlarmClockTool.kt`)：
     - 工具名：`alarm_clock`
     - 参数：
       - `action`: `"set_alarm"` | `"set_timer"` | `"show_clock"`
       - `hour`: Int (0-23)
       - `minute`: Int (0-59)
       - `seconds`: Int (倒计时秒数)
       - `message`: String (标签说明，如“提醒开会”、“煮拉面”)
       - `days`: List<Int>? (重复周期 1-7)
       - `skip_ui`: Boolean (是否在后台静默完成设置)
     - 实现逻辑：通过 `AlarmClock.ACTION_SET_ALARM`、`AlarmClock.ACTION_SET_TIMER`、`AlarmClock.ACTION_SHOW_ALARMS` 调起系统时钟 Intent。
  4. 气泡卡片 UI：
     - 在 `BuiltinToolUIs.kt` 中渲染闹钟/计时器卡片，展示闹钟时间、倒计时时长与操作成功状态。
